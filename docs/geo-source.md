# Источник справочника регионов и городов

Данные о городах России, регионах, федеральных округах и населении загружаются скриптом
web/seo/fetch-geo.mjs из открытого репозитория pensnarik/russian-cities
(https://github.com/pensnarik/russian-cities), данные собраны из Википедии.

Файл web/seo/data/geo.json формируется автоматически, слаги (URL) генерируются транслитерацией,
при совпадении названий городов к слагу добавляется регион.

Обновление справочника: node web/seo/fetch-geo.mjs
Порог "крупного города" меняется переменной окружения: TOP_POP=50000 node web/seo/fetch-geo.mjs

# Семантическое ядро ads.himeet.online

Дата: 2026-11-14. Частотность (колонка «Вордстат») нужно заполнить вручную в https://wordstat.yandex.ru (регион: Россия, точная частота «"!запрос"»). Приоритеты ниже оценочные, не измеренные.

## 1. Как мы конкурируем

Общие запросы вроде «объявления», «купить квартиру», «авто с пробегом» заняты крупными площадками, и там нас не увидят. Реальная ниша:

1. Связка «категория + город» (400+ городов в базе, у большинства площадок страницы слабые).
2. Отличия продукта: чат с автоматическим переводом сообщений, первое объявление бесплатно, вход по телефону, проверка объявлений.
3. Длинные хвосты: «от частного лица», «без посредников», «в районе», «недорого».

Правило честности: не писать в заголовках «без регистрации» и «без SMS» (вход по телефону обязателен), не называть чужие бренды в заголовках и не обещать «безопасных сделок» (гарантий у нас нет).

## 3. Модификаторы для хвостов

| Тип | Примеры |
|---|---|
| Источник | от частного лица, от собственника, без посредников |
| Цена | недорого, дёшево, до 10000 |
| Состояние | б/у, новый, в хорошем состоянии |
| Район и метро | у метро, в центре, + название района |
| Срочность | срочно, сегодня |

Хвосты со словами «срочно» и «рядом» использовать в тексте карточек и FAQ, а не в заголовках: иначе будет похоже на переспам.

## 5. Структура страниц и перелинковка

- Главная -> категории, регионы, 6-8 популярных городов.
- Регион -> его города, категории региона.
- Город -> категории города, соседние города (до 8).
- Категория + город -> родительский город и категория, 4 похожие категории.
- Хлебные крошки на всех страницах (уже есть, с разметкой BreadcrumbList).
- Карточки объявлений (позже): разметка Product/Offer с ценой в RUB.

## 6. Закрыть от индексации

/profile/, /admin/, /auth/, /payments/, /chat/, /api/, /search (уже в robots.txt) и noindex на сами страницы. Пустые страницы «категория + город» без единого объявления выводить в sitemap только после появления объявлений (в сборке флаг indexable остаётся false до запуска).

## 7. Правила против штрафов

1. Не создавать страницы-двойники (один и тот же текст, меняется только город): на каждой странице города минимум 2-3 уникальных абзаца и свой FAQ (поле note в seo.json).
2. Не вставлять списки ключей в текст и в скрытые блоки.
3. Не использовать накрученные «рейтинги» и выдуманные отзывы, только реальные данные.
4. Не показывать роботам другое, чем людям.

## 8. План проверки

1. Подтвердить сайт в Яндекс Вебмастере и Search Console (после перехода основного домена на прямой DNS).
2. Выгрузить частотность по кластерам K1-K5 из Вордстата, заполнить колонки.
3. Через 4-6 недель после индексации открыть «Запросы» в Вебмастере: добавить реальные запросы в ядро, ненужные пометить минус-словами.
4. Запросы с показами без кликов: переписать title.

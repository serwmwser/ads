# ads — Объявления + чат

Отдельное приложение для RuStore, выделенное из HiMeet (himeet.online).
Владелец: самозанятый. Репозиторий: https://github.com/serwmwser/ads

## Состав
- Лента объявлений: категории, города, поиск, фильтры
- Карточка объявления: фото, цена в рублях
- Чат по объявлению с переводом сообщений
- Профиль: мои объявления, мои платежи, жалобы, блокировка, удаление аккаунта

## Чего нет намеренно
Шахматы на ставки, USDC и любая крипта, кошельки, NFT, токены, денежные рефералы,
вход через Google/Apple/Telegram. Запрещено правилами RuStore и/или законом РФ.

## Платежи
Самозанятым платёжные SDK RuStore недоступны с 01.02.2026.
Приём оплаты: ЮKassa (карты + СБП) на сайте, чеки НПД через «Мой налог».
Платёжное решение декларируется в RuStore Консоли. Цены только в рублях.

## Команды
    node web/seo/build-seo.mjs   # генерация SEO-страниц, robots.txt, sitemap.xml
    node web/seo/serve.mjs       # локальный просмотр http://localhost:8080
    node web/seo/indexnow.mjs    # отправка URL в Яндекс (после деплоя)

## Структура
    android/    Android-приложение (Kotlin, WebView + нативный слой)
    backend/    API, авторизация по телефону, платежи
    web/seo/    генератор публичных страниц без зависимостей
    web/public/ готовая статика для поддомена
    legal/      политика, согласие на ПД, оферта, правила сервиса
    docs/       инструкции по RuStore Консоли

## Перед деплоем
Заполните ФИО и ИНН в web/seo/data/seo.json, добавьте favicon.ico и img/og-cover.png.
